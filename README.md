# Agro Calculator

Україномовний статичний сайт із 100 онлайн-калькуляторами, категоріями та редакцією статей. Обчислення виконуються у браузері. Серверної бази даних та сторонніх JavaScript-бібліотек для калькуляторів немає.

## Запуск локально

Потрібен Node.js 22 або новіший.

```bash
npm run build
npm run serve
```

Відкрийте `http://localhost:4173/`.

Перевірки збірки:

```bash
npm test
```

## Публікація на Cloudflare Pages

У налаштуваннях Pages задайте:

- Framework preset: `None`
- Root directory: `/` (корінь репозиторію)
- Build command: `npm run build`
- Build output directory: `dist`
- Node.js: 22 або новіший

Для production-домену використовується `https://agrocalculator.pp.ua`. За потреби адресу можна перевизначити змінною середовища `SITE_URL` без кінцевого слеша. Після кожного розгортання перевіряйте `/sitemap.xml` та `/robots.txt`.

## Додавання статей через CMS

У корені репозиторію є `.pages.yml` — конфігурація Pages CMS. Статті зберігаються у `content/articles/` як Markdown-файли з YAML-метаданими. CMS редагує файли через GitHub, а підключений хостинг запускає нову збірку після коміту.

1. Відкрийте [Pages CMS](https://app.pagescms.org/) та увійдіть через GitHub.
2. Дозвольте сервісу доступ до репозиторію цього сайту.
3. Виберіть колекцію **Статті** та створіть матеріал.
4. Заповніть заголовок, slug, короткий опис, дату, рубрику, теги та текст. Для чернетки залиште `Опубліковано` вимкненим.
5. У блоці **SEO** можна задати SEO Title, Meta Description, Focus Keyword, додаткові ключові слова, canonical URL, index/follow, robots directives і preview, breadcrumb title, тип та власний JSON-LD Schema, Open Graph, X/Twitter, Meta Keywords і Pillar Content.
6. Увімкніть `Опубліковано` та збережіть зміни. Після нової збірки стаття з'явиться на `/articles/`, а її URL буде додано до sitemap, якщо для неї дозволена індексація.

У `content/articles/` є опублікований приклад статті. Його можна відредагувати, зняти з публікації або видалити через CMS.

## Структура проєкту

- `build.mjs` — генератор статичних сторінок, SEO-метаданих, структурованих даних, sitemap і robots.txt.
- `src/catalog.json` — категорії та 100 калькуляторів: поля, формули, приклади, FAQ і ключові слова.
- `public/app.js` — обчислювальна логіка калькуляторів, пошук і меню.
- `public/site.css` — стилі сайту й адаптивна верстка.
- `public/favicon.svg`, `public/social-card.svg` — піктограма й зображення для поширення.
- `content/articles/` — статті у Markdown з SEO front matter.
- `.pages.yml` — редакційна схема Pages CMS.
- `tools/generate_catalog.py` — допоміжний скрипт для відновлення каталогу з його специфікацій.
- `serve.mjs` — локальний сервер попереднього перегляду з `dist/`.
- `dist/` — результат збірки; створюється командою `npm run build` і не зберігається в репозиторії.

## SEO та межі розрахунків

Сторінки калькуляторів генеруються як готовий HTML. Кожна має окремі title і description, заголовок, інструкцію, пояснення вхідних даних, формулу, приклад, FAQ, внутрішні посилання та структуровані дані. Sitemap створюється щоразу, незалежно від змінної середовища.

Курси валют, податкові ставки, тарифи, банківські умови та інші значення, які змінюються, відвідувач вводить самостійно. Калькулятори здоров'я надають довідкові оцінки, а не медичні висновки.
